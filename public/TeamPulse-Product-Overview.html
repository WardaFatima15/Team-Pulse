01 — Overview

What is TeamPulse?

TeamPulse is a purpose-built CRM and remote workforce management platform developed by Binary Next. It gives managers and HR teams complete visibility over their distributed workforce — tracking who is working, when, on what, and how they are performing — all from a single, unified dashboard.

Unlike generic HR tools, TeamPulse is designed to be lean, fast, and opinionated. It removes the complexity of enterprise software while retaining all the features a growing company needs: real-time status, attendance logs, leave workflows, internal support tickets, team chat, AI-powered summaries, and project tracking.

03 — Employees

Employee Management

Every employee in TeamPulse has a dedicated profile page accessible to admins. Profiles contain structured information and a full activity history so managers always have context before a conversation.

Profile Information

  • Full name, email, phone number
  • Role and department assignment
  • Location and timezone
  • Join date and employment history
  • Current status (Online / Away / Offline)
  • Avatar / display initials

Profile Tabs

  • Overview — stats, hours summary, quick metrics
  • Attendance — full clock-in/out history with hours
  • Leaves — all leave requests and their status
  • Tickets — support ticket history per employee
  • Activity — chronological log of all actions
  • Export — download individual timesheet as CSV

When a new employee is added, TeamPulse automatically sends them a welcome email containing their login credentials, portal URL, and role information — no manual onboarding step required.

04 — Attendance

Attendance & Time Tracking

TeamPulse replaces manual attendance sheets with a digital clock-in system. Employees clock in when they start work and clock out when they finish. All records are timestamped and stored permanently.

  • ✓ Daily attendance board — admins see every employee's clock-in time, clock-out time, hours worked, and status for any given day at a glance.
  • ✓ Weekly breakdown — a 5-day table showing each employee's hours per day, colour-coded by threshold (green = 8h+, amber = 4–8h, red = under 4h).
  • ✓ Monthly attendance view — filterable attendance grid with date-range selection covering any calendar period.
  • ✓ Live status indicators — employees who have clocked in but not yet clocked out are shown as "Active" with a pulsing green indicator in real time.
  • ✓ CSV export — full attendance records can be exported to a CSV file with Name, Department, Role, Date, Clock In, Clock Out, and Hours columns. Dates are formatted to prevent Excel auto-conversion issues.
  • ✓ Per-employee timesheet — admins can export a clean timesheet for a specific employee directly from their profile page.

06 — Tickets

Support Tickets & Approvals

TeamPulse includes a lightweight internal helpdesk. Employees raise tickets for IT issues, HR queries, or any matter that requires admin attention. The approvals module consolidates both leave requests and tickets into a single inbox.

  • ✓ Ticket submission — employees create tickets with a title, description, and priority level (Low / Medium / High / Urgent).
  • ✓ Threaded replies — admins and employees exchange messages inside the ticket. Each reply is timestamped and attributed by name.
  • ✓ Status workflow — tickets move through Open → In Progress → Resolved. Admins update status from a dropdown directly in the approvals inbox.
  • ✓ Priority indicators — colour-coded priority badges (red for Urgent, orange for High) make critical tickets easy to spot at a glance.
  • ✓ Unified approvals inbox — a single page shows pending leaves and open tickets in separate tabs, with notification counts in the header bell.
07 — Communication

Team Chat & Communication

TeamPulse has a built-in messaging system so managers can communicate with employees without switching to a third-party tool. Chat is available on both the admin dashboard and the employee portal.

Direct Messages

  • One-to-one messaging between admin and any employee
  • Message history persisted in the database
  • Unread message count shown in notification bell
  • Read receipts to confirm message delivery

Group Chats

  • Create named group chats for teams or departments
  • Add multiple employees to a group
  • All group messages visible to all members
  • Admin can create and manage groups

Video & Voice Calls: TeamPulse supports browser-based video and voice calls between admin and employees using WebRTC — no app installation required. Calls work across different networks and locations via TURN relay servers.

08 — Tasks

Task & Project Management

TeamPulse includes a lightweight project and task tracker designed for remote teams. Admins create projects, break them into tasks, assign them to employees, and track progress — all without needing a separate tool like Jira.

  • ✓ Project creation — create named projects with a colour code and unique key (e.g. "ENG", "MKT"). Projects act as containers for related tasks.
  • ✓ Kanban-style board — tasks are organised by status: To Do, In Progress, In Review, and Done. Drag-and-drop style status management.
  • ✓ Task details — each task has a title, description, priority (Low / Medium / High / Urgent), due date, and an assigned employee.
  • ✓ Employee task view — employees see only the tasks assigned to them in their portal, keeping their workspace focused and uncluttered.
  • ✓ Jira integration — for teams already using Jira, TeamPulse can pull in issues and project data directly, syncing work items without duplication.
09 — AI

AI Assistant

TeamPulse includes an AI assistant built directly into the admin dashboard. It is powered by Anthropic's Claude model and is pre-loaded with context about your team — headcount, attendance patterns, open tickets, and leave data — so it can answer real questions without manual reporting.

What you can ask

  • ✓ "How many employees are currently active?" — pulls live status data
  • ✓ "Which employees have pending leave requests this week?" — scans leave records
  • ✓ "Summarise team attendance for the past month" — generates a readable narrative
  • ✓ "Are there any urgent support tickets open right now?" — queries ticket status
  • ✓ "Write a performance note for [Employee Name]" — HR writing assistance

Responses are streamed in real time — you see the answer being written character by character, just like a chat conversation. The AI stays in scope: it only answers HR and workforce-related questions.

Per-Employee AI Reports

From any employee's profile, admins can trigger a one-click AI report. The report analyses the employee's clock-in patterns, hours worked, leave history, and task completion rate, and produces a readable narrative suitable for a performance review or a management update.

11 — Workspaces

Multi-Tenant Workspaces

TeamPulse is built as a multi-tenant platform. Each client organisation gets a completely isolated workspace — their employees, attendance records, tickets, announcements, and settings are private and never mixed with another organisation's data.

  • ✓ Workspace creation via signup — any company can create their own workspace at /signup by entering their organisation name, admin email, and password. No manual provisioning required.
  • ✓ Complete data isolation — every database query is scoped to the admin's organisation. It is architecturally impossible for one admin to see another organisation's employees or data.
  • ✓ Organisation branding — the workspace name appears in the sidebar and header, giving each client a branded experience on the shared platform.
  • ✓ Scalable by design — there is no limit on the number of organisations or employees. Each new client signup instantly gets a fully functional workspace.

SaaS-ready: TeamPulse can be licensed as a white-label SaaS product. Each client organisation signs up, manages their own team, and operates independently on a shared infrastructure — dramatically reducing per-client deployment cost.

12 — Security

Security & Access Control

  • ✓ Password hashing — all passwords are hashed using bcrypt with a cost factor of 10. Plaintext passwords are never stored.
  • ✓ HTTP-only cookies — authentication tokens are stored in HTTP-only, SameSite cookies. They are not accessible to JavaScript, preventing XSS-based token theft.
  • ✓ Route-level middleware — every admin and employee route is protected by server-side middleware. Unauthenticated requests are redirected to login before any page content is served.
  • ✓ Role separation — admin and employee roles are authenticated independently via separate cookies. An employee token cannot access admin routes.
  • ✓ Organisation-scoped queries — all database queries for admin-facing data are parameterised and scoped by organisationId. Cross-tenant data access is prevented at the query level.
  • ✓ Parameterised SQL — all database interactions use parameterised queries, preventing SQL injection attacks.
13 — Onboarding

Getting Started

Setting up TeamPulse for your organisation takes under five minutes.

1

Create your workspace

Visit the signup page, enter your company name, admin email address, and a password. Your isolated workspace is created instantly.

2

Add your employees

From the Employees page, add each team member with their name, email, role, department, and a temporary password. A welcome email with login details is sent to them automatically.

3

Employees log in

Each employee signs in to the Employee Portal using their email and the temporary password. From there they can clock in, submit leaves, raise tickets, chat, and view their tasks.

4

Manage from the admin dashboard

As the admin, you see everything: who is active, who is on leave, who has pending tickets, and how many hours each person has worked this week. Approve or reject requests with one click.

5

Use AI to stay informed

Ask the built-in AI assistant any question about your team. Generate individual performance reports, or export attendance data to share with payroll or leadership.

14 — Technology

Technology & Infrastructure

TeamPulse is built on modern, proven technologies chosen for performance, reliability, and developer velocity.

Frontend & Framework

  • Next.js 16 (App Router, React Server Components)
  • React 19 with TypeScript
  • Tailwind CSS v4 with dark-first design system
  • shadcn/ui component library
  • Streaming AI responses (Server-Sent Events)

Backend & Data

  • Neon Postgres (serverless, globally distributed)
  • Parameterised SQL via @neondatabase/serverless
  • Anthropic Claude (AI assistant + reports)
  • Resend (transactional email)
  • Vercel (global edge deployment)

Infrastructure

TeamPulse is deployed on Vercel's global edge network, meaning pages load from the server closest to the user anywhere in the world. The database runs on Neon's serverless Postgres, which scales to zero when idle and scales up instantly under load — keeping costs low without sacrificing performance.
